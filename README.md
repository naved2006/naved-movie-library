# 🎬 Cyro Movie Library

A movie discovery web application built with React and Vite.

## 🎥 Output Video

[Click here to watch the project demo](https://drive.google.com/file/d/1q21mwwu0QCfwnlflzBxpstl0gAbUk8ew/view?usp=sharing)

## ✨ Features

- Browse popular movies
- Search movies by title
- View movie details and cast information
- Login and profile pages
- Protected routes using React Router
- Redux state management
- Movie data from TMDB API

## 🛠️ Tech Stack

- React
- Vite
- React Router
- Redux / React Redux
- Axios
- Bootstrap
- TMDB API
